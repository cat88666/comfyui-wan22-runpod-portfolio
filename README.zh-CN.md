# Wan2.2 TI2V 5B ComfyUI / RunPod 可复现工作流

这是为 ComfyUI Builder 应聘准备的作品集，同一个原生工作流支持文生视频与图生视频。

## 交付内容

- 整理并分色的 ComfyUI 工作流 JSON
- RunPod 一键安装、固定版本并启动 ComfyUI 的 Notebook
- 支持续传、自动放入正确目录的模型下载 Notebook
- 日文操作说明、测试记录与申请材料

工作流仅使用 ComfyUI 原生节点。绿色区域是用户输入，紫色区域加载模型，蓝色区域负责采样和输出。默认采用 640×352、49 帧，以降低首次云端验证成本。

## 当前验证状态

已设计为 RunPod / Python 3.12 / CUDA 12.8 环境。结构和敏感信息检查可以在本地完成；GPU 生成结果、耗时和显存数据将在 RunPod 实机验证后记录，未验证前不会宣称运行成功。
